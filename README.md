# Frontline performance dashboard

A personal, browser-based prototype for reviewing frontline service performance and coaching opportunities. It uses **sample data** and contains no confidential company records.

## What it shows

- Weighted scores across customer interaction, product knowledge, transparency, efficiency, team collaboration, and policy-aligned offers.
- A searchable, sortable associate table with status labels and summary metrics.
- A detail drawer with category scores, checklist items, strengths, and coaching notes.

## Run locally

Open `index.html` in a modern browser. No server, account, API key, or build step is required. The sample records are defined in `app.js`; editing them changes what the dashboard displays.

## Scope

This is a **front-end demo**, not a deployed employee evaluation system. The labels and coaching prompts illustrate a workflow; the scores are supplied in the sample data, not generated by a trained model. The UI is built with HTML, CSS, and vanilla JavaScript.
